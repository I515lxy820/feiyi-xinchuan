# AI 素养大赛答题与模拟训练助手实施计划

## Context

用户希望围绕湖北省高职高专院校“AI+信息素养”大赛搭建快速答题流程，支持文字与题目截图、联网核对、自动解题、模拟训练和错题改进，目标准确率为 80% 以上。已访问赛事首页，公开内容主要是报名通知、赛事进程和培训资源，尚未发现可直接使用的公开题库或练习接口。

当前 `/workspace` 只有“非遗心传”相关 HTML/Markdown，没有可复用的答题系统。因此将在独立目录 `/workspace/ai-literacy-assistant` 新建项目，不修改现有作品。

默认交付独立网页助手：系统自动识别并解答文本/图片题，展示答案、解析、来源和置信度，用户人工核对后再到官方平台作答。第一版不自动登录或提交正式比赛、不处理验证码；如后续赛事规则明确允许，再单独适配练习页或比赛页。

“80% 以上”作为独立保留测试集的验收门槛，不作未经验证的保证。训练提升指错题重练、薄弱点分析和经过回归测试的提示词/检索策略优化，不声称在线修改模型参数或每轮必然提升。

## 推荐架构

采用 **FastAPI + SQLite + 同源静态 HTML/CSS/JavaScript**，避免引入不必要的前端框架、独立 OCR、向量数据库或任务队列。

处理链路：

1. 用户粘贴题干或上传截图。
2. OpenAI 兼容视觉模型识别题目并生成候选答案、解析、置信度和搜索词。
3. 调用可配置中文搜索 API，获取真实标题、摘要和 URL。
4. 模型依据搜索摘要复核答案；后端合并真实来源，禁止模型编造 URL。
5. 返回规范答案、解析、来源、置信度及“需要人工复核”标记。
6. 模拟题在解题完成后才由服务端读取标准答案并判分，保存错题、反馈和各阶段耗时。

文本题可将初答与检索并发执行；图片题先识别再检索。通过异步请求、连接复用、有限搜索数量、图片压缩、明确超时和搜索缓存降低延迟。检索失败或来源冲突时明确显示“未完成联网核实”，不伪装成功。

## 功能范围

### 快速答题

- 支持单选、多选、判断、填空/简答。
- 支持粘贴文字及 JPEG、PNG、WebP 截图；校验格式和大小，压缩图片，不默认保存原图。
- 统一返回识别题干、规范选项答案、解析、置信度、真实来源、警告及耗时。
- 图片识别不全、答案与选项不匹配、检索失败、来源冲突、初答与复核变化或置信度偏低时，醒目标记人工复核。
- 页面展示“识别—检索—复核”状态，结果中的模型内容和搜索摘要以纯文本渲染。

### 模拟训练与复盘

- 导入带可靠标准答案的 JSON/CSV 模拟题，校验题型、选项和答案并去重。
- 每轮执行抽题、自动作答、判分、错因归类和统计；客观题采用规范化精确匹配，多选必须集合完全一致。
- 支持按主题和错题重练，展示上次答案、标准答案及修正解析。
- 保存练习轮次、准确率、题型/主题薄弱点及模型、搜索、复核和总耗时。
- 简答题单独人工评分，不与客观题自动准确率混算。
- 提示词、检索或置信度阈值每次调整均记录版本；只有在 practice/dev 数据回归后启用。

### 准确率与速度验收

- 数据分为 `practice`、`dev`、`holdout`；保留集不进入日常题库、提示词示例、错题库或答案缓存。
- 导入时进行哈希去重及近重复检查，避免同一道题换措辞后同时出现在调优集和测试集。
- 主指标为 `正确数 / 全部测试题数`；超时、格式错误和拒答都计为错误，避免通过弃答抬高准确率。
- 同时报告图片题/文本题、各题型准确率、作答覆盖率、Wilson 置信区间及 p50/p95 延迟。
- 固定模型、温度、提示词和搜索配置，评测时关闭答案缓存。
- 只有足够题量且未参与调优的冻结测试集原始准确率达到 80% 才通过验收；不足时只报告样本结果。若根据保留集反复调优，则更换新的未见测试集。

## 关键文件

- `/workspace/ai-literacy-assistant/app/main.py`：FastAPI 入口、API 路由、静态页面与健康检查。
- `/workspace/ai-literacy-assistant/app/schemas.py`：请求、响应、题型、答案和来源的数据契约。
- `/workspace/ai-literacy-assistant/app/solver.py`：文本/图片解题、检索复核、低置信度判定与统一流水线。
- `/workspace/ai-literacy-assistant/app/providers.py`：OpenAI 兼容模型及搜索服务适配、超时和有限重试。
- `/workspace/ai-literacy-assistant/app/db.py`：SQLite 表、练习轮次、作答、反馈、错题和统计。
- `/workspace/ai-literacy-assistant/static/index.html`、`app.js`、`styles.css`：快速答题、模拟训练、错题本、统计和设置说明界面。
- `/workspace/ai-literacy-assistant/scripts/import_questions.py`：模拟题校验、去重和导入。
- `/workspace/ai-literacy-assistant/scripts/evaluate.py`：冻结测试集评测、泄漏检查和指标输出。
- `/workspace/ai-literacy-assistant/tests/`：解题、搜索异常、判分、数据隔离和端到端测试。
- `/workspace/ai-literacy-assistant/.env.example`：仅列配置变量，不包含真实密钥；`.env` 和本地数据库加入 `.gitignore`。

核心接口包括 `POST /api/solve`、`GET /api/practice/next`、`POST /api/practice/{id}/solve`、`POST /api/attempts/{id}/feedback`、`GET /api/mistakes`、`GET /api/stats` 和 `GET /api/health`。

## 实施步骤

1. 建立独立项目、配置、数据契约和 SQLite 表，使用模拟模型/搜索适配器打通完整流程。
2. 实现快速答题页面、文本与截图上传、严格 JSON 输出校验及规范答案。
3. 接入视觉模型和一家实际可用的搜索服务，完成真实来源复核、异常提示与低置信度策略。
4. 实现模拟题导入、自动判分、错题反馈、错题重练、轮次对比和性能统计。
5. 实现 practice/dev/holdout 隔离、去重和评测脚本，确保解题提示词无法读取标准答案。
6. 完成模拟服务测试、真实密钥冒烟测试及浏览器端文本/图片流程测试。
7. 有真实模拟题后先测基线，仅根据 practice/dev 改进，最后运行冻结测试集并报告是否达到 80%，不隐瞒失败样本和延迟。

## 验证

- 单元/集成测试覆盖：文本和图片输入、多选判分、无效模型 JSON、搜索超时、无来源、来源冲突、低置信度、非法图片及密钥不泄露。
- 使用临时 SQLite 验证“获取练习题—自动解题—判分—反馈—错题重练—统计”完整闭环。
- 检查标准答案不会进入模型请求，保留集不会进入运行时题库、静态资源、示例或普通日志。
- 在浏览器完成一次文本答题和一次截图答题，确认答案、来源、复核提示及加载状态可见。
- 默认测试不调用付费外部服务；提供密钥后显式运行在线冒烟测试。
- 最终输出测试题量、原始准确率、分类准确率、置信区间和 p50/p95 延迟，以结果决定是否通过验收。

## 用户后续需要提供

- 支持图片输入的 OpenAI 兼容模型：`MODEL_API_KEY`、`MODEL_BASE_URL`、`MODEL_NAME` 和可用额度。
- 一家搜索服务的 `SEARCH_API_KEY`、接口类型/文档及可用额度。
- 带可靠人工标准答案的模拟题，以及未用于调优的独立验收题；不能用同一模型自答结果直接充当金标准。

密钥只放在服务端环境变量或本地 `.env`，不会写入前端、日志或答复。页面会明确提示题目图片将发送给模型供应商、搜索词将发送给搜索供应商。公开部署前还需增加身份认证、限流和 HTTPS；本地单用户版本不收集比赛账号、密码或验证码。
